# HW3 RQ1–RQ5 實驗解讀

標註來源：PubMed 主題參考＋摘要弱規則回退；自動二元參考標籤，非人工或官方查詢標準答案。

固定查詢共 10 個；平均指標納入 10 個，排除 0 個。其中尚未標註 0 個；已判讀但尚無已知相關文件 0 個。

只有已有相關文件的查詢納入平均；排除查詢並未被當成零分，也不能將少數查詢的平均解讀為已完成全部查詢。已判讀但未找到相關文件，不代表整個語料沒有相關文件。逐查詢狀態及排除原因見 query_status.csv。

## RQ1：原始 TF 與 Log TF

原始 TF 隨重複次數線性增加；Log TF 使用 1+log10(f)，將 f=1、2、10 轉成 1、1.301、2，抑制大量重複。文件與查詢使用同一公式，不能只改文件權重。

## RQ2：IDF

標準 IDF=log10(N/DF)。DF 越大、IDF 越小；出現在所有文件的詞 IDF=0。平滑版額外加 1，使這類詞保留權重。IDF 衡量區辨力，不等於醫學重要性。

## RQ3：TF、IDF 與 TF-IDF 的排名

TF 反映重複，僅 IDF 使用詞項出現與否，TF-IDF 同時使用文件內頻率與跨文件區辨力。控制語料、前處理、查詢、IDF 形式與 cosine 後，再比較逐查詢排名；沒有預設最佳方法。

## RQ4：L2 normalization

對非零向量，cos(q,d)=q·d/(||q||||d||)，等於兩個 L2 單位向量的點積。所以正確 cosine 在顯式正規化前後分數與排名相同（容許浮點誤差）。raw dot 與 normalized dot 的差異另列為補充對照，不能將 raw dot 稱作 cosine。完整檢查見 normalization.csv。

## RQ5：評估指標

P@k 的分母固定為 k；MRR 為完整返回排名的第一個已知相關結果倒數；nDCG@k 使用 gain=2^grade−1；Recall@k 的分母是已知相關文件數。未標註不同於人工判為不相關，但此處評分時先按 0 處理，同時報告 judged@k。

## PubMed 參考標籤的規則與限制

每個查詢的兩組概念均須由 MeSH、藥物／化學物質、補充概念或關鍵字支持，才記為 metadata 正例。缺少欄位或概念依據不足時，獨立套用原摘要 weak rule；不是把缺少 MeSH 當作不相關。所有規則先於比較固定，不使用排名或分數。0／1 是規則結果，沒有人工確認的 2 級相關性。

reference_rules.json 保存完整詞表；reference_labels.csv 保存逐筆來源、理由與欄位依據；reference_coverage.csv 與 reference_topk_sources.csv 揭露回退比例及前 k 名來源。pubmed_metadata.json 保存原始欄位、XML hash 與抽取指紋。

Recall 僅為規則參考集合 Recall；nDCG 採二元 gain。主題共現不保證研究關係、主要終點或醫學效度。MeSH 不全為人工標引；關鍵字及回退仍可能偏向詞彙方法。參考 docs/PUBMED_REFERENCE.md。

若使用自動參考或弱標籤，數字只驗證實驗流程與此規則下的表現，不能聲稱已證明真實檢索品質。人工標註可由多方法 Top 20 的聯集起步，但需交代 pooling 偏差，並補查池外文件。
