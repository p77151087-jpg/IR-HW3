# HW3 RQ1–RQ5 實驗解讀

標註來源：PubMed 主題參考＋摘要弱規則回退；自動二元參考標籤，非人工或官方查詢標準答案。

固定查詢共 10 個；平均指標納入 10 個，排除 0 個。其中尚未標註 0 個；已判讀但尚無已知相關文件 0 個。

只有已有相關文件的查詢納入平均；排除查詢並未被當成零分，也不能將少數查詢的平均解讀為已完成全部查詢。已判讀但未找到相關文件，不代表整個語料沒有相關文件。逐查詢狀態及排除原因見 query_status.csv。

## RQ1：原始 TF 與 Log TF

原始 TF 隨重複次數線性增加；Log TF 使用 1+log10(f)，將 f=1、2、10 轉成 1、1.301、2，抑制大量重複。文件與查詢使用同一公式，不能只改文件權重。

## RQ2：IDF

標準 IDF=log10(N/DF)。DF 越大、IDF 越小；出現在所有文件的詞 IDF=0。平滑版額外加 1，使這類詞保留權重。IDF 衡量區辨力，不等於醫學重要性。

## RQ3：TF、IDF 與 TF-IDF 的排名

TF 反映重複，僅 IDF 使用詞項出現與否，TF-IDF 同時使用文件內頻率與跨文件區辨力。控制語料、前處理、查詢、IDF 形式與 cosine 後，再比較逐查詢排名；沒有預設最佳方法。

## RQ4：L2 normalization

本次依題目只將文件向量 d 正規化為 d'=d/||d||，查詢 q 的權重保持原值。前後皆用標準 cosine：cos(q,d')=q·d'/(||q||||d'||)。因此文件 L2 前後分數與排名相同（容許浮點誤差）；查詢沒有另做 L2。raw dot 與 cosine 的不同 scoring 另列補充對照；文件 L2 後的點積仍須除以查詢 norm，不能將它或 raw dot 直接稱作 cosine。完整檢查見 normalization.csv，明記 documents_only、查詢 norm 不變、是否可比較及差值。零結果列略過；僅含原五種向量方法，第六種 BM25 不適用此 L2 等價檢查。

## 第六種方法：BM25

原五種方法保留 log10 向量權重與 cosine。BM25 是另一種 scoring 模型，並非 cosine 或第六種對稱向量權重。
固定參數 k1=1.2、b=0.75，未針對參考標籤調參。
BM25_IDF=log10(1 + (N - DF + 0.5) / (DF + 0.5))；score=sum(query_tf * BM25_IDF * f * (k1 + 1) / (f + k1 * (1 - b + b * dl / avgdl)))。
dl 是前處理後的摘要 token 數，avgdl 含所有 N 篇；查詢重複詞按實際 TF 線性累加，OOV 忽略。
BM25 使用自己的固定 IDF，不受 standard／smooth 選項影響；不做顯式 L2、不裁切至 0–1。
只比較排名指標，不能將 BM25 原始分數直接與 cosine 大小比較。BM25 也屬詞彙方法，仍受自動標籤偏差影響。

## PubMed 參考標籤的規則與限制

每個查詢的所有概念組均須由 MeSH、藥物／化學物質、補充概念或關鍵字支持，才記為 metadata 正例。缺少欄位或概念依據不足時，獨立套用原摘要 weak rule；不是把缺少 MeSH 當作不相關。所有規則先於比較固定，不使用排名或分數。0／1 是規則結果，沒有人工確認的 2 級相關性。

reference_rules.json 保存完整詞表；reference_labels.csv 保存逐筆來源、理由與欄位依據；reference_coverage.csv 與 reference_topk_sources.csv 揭露回退比例及前 k 名來源。pubmed_metadata.json 保存原始欄位、XML hash 與抽取指紋。

Recall 僅為規則參考集合 Recall；nDCG 採二元 gain。主題共現不保證研究關係、主要終點或醫學效度。MeSH 不全為人工標引；關鍵字及回退仍可能偏向詞彙方法。參考 docs/PUBMED_REFERENCE.md。

若使用自動參考或弱標籤，數字只驗證實驗流程與此規則下的表現，不能聲稱已證明真實檢索品質。人工標註可由多方法 Top 20 的聯集起步，但需交代 pooling 偏差，並補查池外文件。

## 本次 TF/DF 查詢設計

Q01–Q04 為高 TF／高 DF、低 TF／高 DF、高 TF／低 DF、低 TF／低 DF；Q05–Q10 為四類的六種兩兩搭配。
類別依 C 基準的命中文件平均 TF 與 DF 比例；每篇文件仍使用實際 TF。完整分布與門檻保存於 query_design.json。
單詞 cosine 查詢端的正權重倍數會抵消，文件端 weighting／完整 norm 仍不同。雙詞可觀察相對詞項權重的影響。
配對參考集合要求兩個概念同時成立；檢索本身依非零分數排序，不是 AND 篩選。
少數配對的參考正例可能少於 k；P@k 分母仍固定 k，不用製造標籤補滿。這些是自動概念代理標籤，並非人工答案。
