# HW3 需求對應

| 題目要求 | 實作與操作位置 | 驗證方式 |
|---|---|---|
| 文字前處理、詞項統計 | `core.terms`、`Engine.counts/df/cf`；語料頁 | 生醫複合詞、文件 TF 與集合 CF 的手算測試 |
| 原始 TF、Log TF、IDF、TF-IDF | 五種權重；語料頁公式、搜尋方法選擇 | `test_weight_hand_calculations` |
| 文件向量正規化 | 顯式 L2 選項及正規化對照 | 五方法 × 十查詢分數／排名等價檢查 |
| 文件與查詢同詞彙空間 | 同 tokenizer、設定與權重；保留查詢重複 TF | 重複查詢與 OOV 手算測試 |
| cosine 與降序排名 | `Engine.rank` | 手算 cosine、零向量、同分與長度測試 |
| 前 10 名與分數 | 搜尋頁表格、摘要、權重貢獻 | 實際 Streamlit AppTest |
| 控制變因對照 | 側欄共用設定、方法比較頁、固定 snapshot | manifest 與逐查詢排名輸出 |
| 至少 10 個查詢 | `data/queries.json` | 完整語料整合測試 |
| 每查詢相關性判斷依據 | 人工等級與 reason；CSV 匯入／匯出 | 驗證理由、語料／查詢版本、原子儲存 |
| 可完成的人工標註流程 | 逐篇完整摘要、跨頁草稿、儲存回饋與衝突防護 | UI 切換保留、缺理由／寫入失敗保留、並發更新測試 |
| P@k、Recall@k、MRR、nDCG | `evaluation.metrics`、效能比較頁 | 已知 graded relevance 的手算測試 |
| 評估樣本及限制 | 三種查詢狀態、納入／排除原因、零母數未計算 | `query_status.csv`、summary／manifest／RQ 母數一致性測試 |
| 實驗保存與重現 | 獨立 run、拒絕覆寫、歷史比較與輸出 hash | 兩次獨立 run 逐位元核對；來源／判讀版本不符拒絕受控比較 |
| RQ1–RQ5 | 自動生成解讀與報告模板 | 根據自己的人工標註補上實證結論 |
| 系統說明、結果與 demo | README、離線 CLI、四頁 UI | 本機啟動與瀏覽器核對 |

## 需要使用者完成的學術判讀

2026/10/15 使用者另指定以 PubMed 主題詞、藥物、關鍵字建立自動參考，依據不足時回退原摘要 weak rule。已增加獨立來源 `pubmed_hybrid`，十查詢的可重現判據與限制見 `PUBMED_REFERENCE.md`。這可用於揭露來源的自動評估；不必為執行此流程先填人工標註。下述人工判讀仍保留為獨立效度驗證的待辦，不將自動來源冒充人工答案。

人工標註初始留空。規則弱標籤只供完整流程示範，沒有冒充人工判讀。正式分析需閱讀摘要、對至少 10 個查詢建立相關集合與理由，並說明主題、抽樣與不完整標註的限制。題目列多種指標為選用範例，此實作均提供。

使用者於 2026/10/15 確認依查詢意圖納入人體、動物與細胞研究，理由需註明類型。其他納排界線見 `ANNOTATION_GUIDE.md` 的待確認事項；逐篇學術判斷仍須由使用者完成。約 6 分 30 秒的四頁展示流程見 `DEMO.md`。

題目「GLP-1，約 3,000 篇」是建議情境，未明定最低篇數。此版依使用者要求擴充為 3,000 篇快照，保留原 1,000 篇基準。若教師另有公告，應以最新公告為準。

## RQ4 的數學界線

標準 cosine 對正的向量縮放不變，因此顯式 L2 正規化前後理論上相同。這是可如實報告的實驗結果。長度造成的變化以 raw dot 與 normalized dot 補充呈現，並清楚標示 scoring。
