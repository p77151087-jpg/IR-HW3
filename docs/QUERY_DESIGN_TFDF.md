# 十個 TF/DF 預設查詢的設計

四類代表詞＋六種兩兩搭配；分類基準為固定 3,000 篇、C 前處理。
TF 是單篇文件詞頻；本表用『命中文件平均 TF』摘要分布，不以 CF 當作文件 TF。
高 TF ≥3、低 TF ≤1.6；高 DF ≥20%、低 DF ≤5%。未命中文件不計入平均 TF，DF 則以全部文件為分母。

搜尋與方法比較的選單將條件標在查詢詞右側，例如 `Q01 · GLP-1（高 TF 高 DF）`、`Q05 · GLP-1 receptor（1 搭配 2）`；括號僅供說明，不加入實際查詢或正式評估。

配對查詢各含一個代表詞；查詢中每個詞只輸入一次。高／低 TF 描述語料中的分布，不保證每篇文件都相同。
本設計沒有依評估分數選詞；自動相關標籤依公開概念規則另建，並非 TF 高低的人工判斷。

## 原則與版本

高低是本教學案例的預先門檻，不是對詞項的普遍定義。高 DF：至少 600／3000 篇；低 DF：至多 150／3000 篇。平均 TF 只在包含該詞的文件上計算，並另列中位數、範圍與 CF 供檢查。每篇文件的計分仍使用自己的 TF。

類型依 C 預處理下的精確 token 統計；B／D 可切換，網站會揭露當前詞形與統計，不將舊分類冒充全部設定的結果。查詢各詞只輸入一次，沒有用重複查詢詞製造高 TF。

單詞資訊需求為各代表概念；配對要求同時涵蓋兩概念。PubMed 中介資料不足時回退摘要全部概念組，所有規則與別名保存於 `data/reference_rules/pubmed-tfdf-v1.json`。分類沒有依排名、P@k 或標籤調整；標籤不因 TF 高低改變。自動參考仍有詞彙偏差，不構成人工驗證。

舊十查詢及其規則完整封存於 `data/query_sets/<舊 queries SHA256>/`；舊實驗與報告不回寫。新規則綁定整份 queries fingerprint，不能只憑同名 Q01 套用舊答案。人工資料按 corpus＋queries 分流；CSV 仍驗證版本。

新查詢與新標籤形成新的實驗基準，不能和舊疾病／藥物查詢的平均指標直接當成受控改善。候選池含六方法各 Top 20，可能有 pooling bias，保留池外補查。

重現設計：`.venv\Scripts\python.exe -B -X utf8 scripts\design_tfdf_queries.py`。相同版本只核對，不重新選詞；語料統計不符會拒絕沿用分類。
