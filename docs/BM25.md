# 第六種檢索方法：BM25

2026/10/16 依使用者要求，在原五種 log10 向量方法之外增加 BM25。搜尋、方法比較、Top 10 變化、效能評估、候選池、CLI 與實驗匯出皆包含六種方法；舊五方法的歷史 run、ln／log10 報告、語料及人工標註均保留。

## 公式與固定參數

```text
BM25_IDF(t) = log10(1 + (N - DF(t) + 0.5) / (DF(t) + 0.5))
BM25(q,d) = Σ[t in q ∩ vocabulary] qtf(t) × BM25_IDF(t)
            × f(t,d)(k1+1) / [f(t,d) + k1(1-b+b×dl/avgdl)]
k1 = 1.2
b = 0.75
```

- `N` 包含所有固定快照文件；`DF` 取同一前處理後詞彙表，僅摘要正文計分。
- `dl` 是前處理後摘要 token 數，包含重複詞；`avgdl=Σdl/N`，包含可能變成空摘要的文件。不能用詞彙種類數或 L2 norm 代替。
- 文件與查詢沿用相同 B／C／D 前處理。查詢保留實際重複 TF，按 `qtf` 線性累加，未另加 k3 飽和項；OOV 忽略。
- 常見詞 `DF=N` 仍有正的 BM25 IDF。空白、前處理後空查詢、全 OOV 或空詞彙表安全返回空結果；不補零分文件。
- 排序沿用分數取 12 位小數後降序、數字 PMID 升序的同分規則。畫面顯示 6 位小數，CSV 保留原始精度。

BM25 使用獨立 scoring，並非第六種 cosine 向量權重。原五種方法的標準／平滑 IDF 選項不影響 BM25；BM25 不做顯式 L2、不裁切至 0–1。API 對 BM25 明確指定 cosine、dot 或 normalize=True 會拒絕；網站若勾選 L2 後選 BM25，會明示不適用並略過 L2。

詞頻飽和與長度校正的形式參考 [Stanford 資訊檢索教材](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html)；正值 IDF 形式及預設 k1／b 參考 [Apache Lucene BM25Similarity 文件](https://lucene.apache.org/core/9_12_2/core/org/apache/lucene/search/similarities/BM25Similarity.html)。本專案明確採 log10、精確 token 長度及線性 query TF，沒有宣稱與 Lucene 分數逐位元相同。固定底數切換只會將 BM25 全部分數乘上同一正數，理論上不改排名；這與含 `1+log(f)` 的 Log TF 不同。

## 比較與評估界線

六種方法共用相同 3,000 篇、十查詢、前處理、參考標籤及 k。原五方法可研究 weighting 的影響；加入 BM25 同時改變 IDF、TF 飽和、長度校正及 scoring，不能把差異全部歸因於某一個 weighting 因素。參數先固定，未依這批參考標籤挑選最佳參數。應比較 P@k、參考集合 Recall@k、MRR、nDCG@k 與名次，不直接比較不同模型的原始分數。

PubMed 中介資料＋摘要 weak rule 仍是自動二元參考，沒有新增人工判讀。BM25 也使用詞彙訊號，因此相同的 lexical bias 仍然存在；加入 BM25 不會把參考標籤轉為人工真值，也不能預設它一定勝出。

候選池改為六種方法各 Top 20 的聯集，可能增加待讀文件，但不修改既有人工判讀。池外補查、未標註與不相關的區分、標註版本及 pooling bias 規則均保留。

## 保存與重現

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m ir_hw3.cli search 'semaglutide weight loss obesity' --method bm25
.\.venv\Scripts\python.exe -B -X utf8 -m ir_hw3.cli experiment --source pubmed
.\.venv\Scripts\python.exe -B -X utf8 scripts\verify_hw3.py
.\.venv\Scripts\python.exe -B -X utf8 scripts\evaluate_pubmed_reference.py
```

新 run 的 manifest 記錄六方法、逐方法 scoring、BM25 參數、IDF／完整公式、query TF 與長度定義、資料／程式／輸出 hash。`normalization.csv` 僅保留原五方法的 50 組 L2 檢查，manifest 明列 BM25 不適用，不偽造第六種方法的通過紀錄。舊五方法歷史按當時 manifest 的方法清單讀取，不因加入新方法而消失；跨五／六方法或 BM25 參數不同的歷史比較不會被誤列為相同控制條件。

`verify_hw3.py` 以獨立 NumPy 公式核對 B／C／D × 標準／平滑 IDF 下的五方法 cosine 與 BM25 分數，並建立兩次新的 weak_rules run 核對逐位元重現性。正式六方法自動參考結果由新的 PubMed hybrid run 產生；歷史五方法報告不回寫數字。
