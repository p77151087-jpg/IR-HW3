# TF/DF 查詢集的人工判讀指南

本版適用 `tfdf-v1`。舊十個疾病／藥物資訊需求的指南已保留於 `docs/archive/biomedical-intents-v1/ANNOTATION_GUIDE.md`，不能將其 Q01 判讀直接套用至新 Q01。

## 判讀等級與理由

- -1：尚未判讀，或證據不足而待確認。不要當成不相關。
- 0：已讀摘要，未實質涵蓋此查詢的概念需求。
- 1：實質討論所需概念，但可能只是研究的一部分或背景。
- 2：所需概念是研究的主要焦點；配對須確認兩者具有實質關聯。

理由應指出摘要證據、研究類型（人體／動物／細胞／綜述等）與判斷界線。依使用者已確認的範圍，這些研究類型可依查詢意圖納入；不因研究沒有正面療效而判不相關。

TF/DF 類別用於比較 weighting；TF 高、DF 低、命中很多詞或排名高都不等於人工相關。可辨認同義表達，也可將只有背景共現的文章判為 0。不要直接複製自動規則結果當成人工判讀。

## 十個資訊需求

四類代表詞＋六種兩兩搭配；分類基準為固定 3,000 篇、C 前處理。
TF 是單篇文件詞頻；本表用『命中文件平均 TF』摘要分布，不以 CF 當作文件 TF。
高 TF ≥3、低 TF ≤1.6；高 DF ≥20%、低 DF ≤5%。未命中文件不計入平均 TF，DF 則以全部文件為分母。

本設計沒有依評估分數選詞；自動相關標籤依公開概念規則另建，並非 TF 高低的人工判斷。

Q01–Q04 看是否實質涵蓋相對應的 GLP-1、受體、MASLD 或高血壓概念；Q05–Q10 需同時涵蓋各配對概念。針對「何種程度算實質討論、配對關聯的最低標準」仍需使用者逐篇確認，本指南未預填人工答案。

## 工作流程與限制

由六種方法各 Top 20 聯集閱讀；可切至全語料補查池外文件。記錄候選池大小、已讀與未讀、正例數及補查方式。池內全讀完仍不代表完整語料。

草稿跨頁保留於同一連線，儲存後才納入評估；關閉或重整前先儲存或下載備份。理由必填，未標註不同於不相關。新查詢使用獨立 queries fingerprint 與人工路徑；舊人工 JSON／CSV 不自動遷移。

報告需揭露納入平均的實際查詢數、排除原因、judged@k、已知相關集合 Recall、不完整判讀與 pooling bias。自動參考可繼續執行，但不能寫成已人工驗證。
