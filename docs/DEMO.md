# HW3 操作展示（目前網站，約 6 分 30 秒）

2026/10/26 同步目前介面。核心展示使用四個檢索工作頁；第五頁「Embedding／TF-IDF 詞彙關聯」為追加展示。先前包含人工標註頁籤、來源切換與舊查詢的操作稿保留於 `reports/requirements-review-20261026/DEMO.md.before`；更早的疾病／藥物查詢稿保留於 `docs/archive/biomedical-intents-v1/DEMO.md`。

## 展示前

- 開啟 <http://127.0.0.1:8503/>。能使用就沿用服務，不重複啟動，不操作 HW2 服務。需要啟動時依 README 使用 HW3 的 `start_hw3.cmd`。
- 確認固定 3,000 篇英文摘要、C 前處理及標準 log10(N/DF)。原五方法使用 cosine，BM25 固定 k1=1.2、b=0.75 並使用自己的 IDF。更換方法時維持同一查詢與其他設定。
- 目前十查詢為 GLP-1、receptor、MASLD、hypertension 四個單詞，以及其六種兩兩配對。Q07 為 GLP-1 hypertension，Q10 為 MASLD hypertension；Q01 不再指舊的藥物／疾病句子。
- 評估固定使用「PubMed 主題參考＋弱規則回退」，不是人工判讀。網站沒有人工標註／實驗紀錄頁籤，也沒有評估來源切換選單。既有人工檔及歷史實驗仍保留。
- 先練習以下流程，展示時使用畫面當下的數值；個人操作與回答問題仍須由本人完成。

## 操作與講稿

| 時間 | 操作 | 說明重點 |
|---|---|---|
| 0:00-0:45 | **語料與設定**：指出 3,000 篇、31,662 詞、10 查詢；查看方法／意義表，再搜尋 GLP-1 或 MASLD 的 CF／DF／IDF。 | 「C 是切詞加移除停用詞，不做 stemming。TF 是單篇詞頻，CF 是整體次數，DF 是包含該詞的文件數。常見詞 IDF 較低，代表區辨力較低，不是醫學上不重要。」公式欄已移除，計算仍存在於程式與報告。 |
| 0:45-1:45 | **搜尋與排名**：預設選 Q01，方法選 Log TF×IDF，按「搜尋」。看前十名、cosine 分數、查詢詞命中次數、摘要總詞數；讀一篇摘要及「詞項與計分」。 | 「文件與查詢共用前處理、詞彙表與 weighting，僅摘要正文計分。命中次數與摘要詞數不等於向量 norm；分數也不是正確率。Log TF 讓重複詞的邊際加分遞減。」 |
| 1:45-2:45 | **方法比較**：先選 Q07，再選 Q10，觀察六方法同一 PMID 的名次及新進／移出文章。點表頭切換排序；數字越小名次越前面。 | 「原五方法固定其他條件，只改 weighting；BM25 是不同 scoring，不能直接比較它與 cosine 的分數大小。TF-IDF 並非每個查詢都勝出。」品質判斷在下一個評估步驟用固定參考標籤確認。 |
| 2:45-3:45 | 同頁選回 Q01，往下到 **L2 正規化前後比較**，權重選 Log TF×IDF；看查詢與文件長度、完整排名一致、最大分數差及逐篇分數。再看下方 raw dot／cosine。 | 「依題目只正規化文件，查詢權重保持原值；文件長度變成 1，查詢長度不變。cosine 本來就除以向量長度，因此排名等價，細微分數差是浮點誤差。raw dot 是另一種 scoring，不能當成未正規化 cosine。BM25 不套用此比較。」 |
| 3:45-5:15 | **效能評估**：k 選 10，圖表先選「全部查詢平均」，按「執行六種方法評估」；看四張獨立長條圖，再選 Q07、Q10，最後切回平均。 | 「六種方法對十個查詢各自排名、計算指標，再對可納入查詢平均；目前是 10/10。Precision／Recall／nDCG 看前 k 名，MRR 用完整排名；單查詢顯示 RR。不同查詢及指標可能有不同優勝方法。」 |
| 5:15-6:30 | 展開 **弱規則是什麼？十個查詢如何評估？** 及 **評估依據與查詢明細**；看概念組、來源涵蓋率與逐筆標籤。最後展開 **下載與保存實驗**，示範 CSV 或獨立 run。 | 「先看 MeSH、藥物／化學物質、關鍵字等主題證據；不足時才獨立用摘要概念詞回退。配對查詢須兩組概念都成立，但共現不保證研究關係。這是自動參考，不是人工真值；Recall 只相對於規則集合。保存的 run 含設定、排名、指標、標籤、公式與來源 hash，不覆寫舊成果。」 |

## 可引用的固定結果

以下數字來自目前十查詢的 PubMed 主題參考＋弱規則回退結果。若展示時變更 k，應改用當次畫面數值。

- Q07 的 P@10：TF 0.10、Log TF 0.60、IDF-only 0.90、TF-IDF 1.00。
- Q10 的 P@10：TF-IDF 0.00、IDF-only 0.50；Q10 的十個參考正例全部來自弱規則回退，結論需特別保留限制。
- 五種向量方法中，平均 P@10 最高為 Log TF-IDF 0.89；平均 nDCG@10 最高為 Log TF 0.9034。補充 BM25 的平均 P@10 為 0.94、nDCG@10 為 0.9576。
- 僅文件 L2、查詢保持不變的五方法×十查詢共 50 組比較，完整排名全部相同；最大分數差約 2.22e-16。不能將這個數值說成評估正確率。

## 追加展示（時間允許或教師另外要求時）

- **BM25**：說明 k1=1.2 控制詞頻飽和，b=0.75 校正摘要長度；本批摘要存在重複主題詞與篇幅差異，故採兼顧兩者的預設基準，沒有宣稱已調參得到最佳值。
- **Embedding／TF-IDF 詞彙關聯**：可選 semaglutide 比較相關詞，再看平均 Top-10 重疊率、熱圖或散點。TF-IDF 看跨文章分布，Embedding 看上下文；四組模型均採 C 前處理。重疊率是清單一致程度，不是檢索正確率，也不是這份原題五項核心任務的替代品。
